# ProSport Oberá

Tienda demo (HTML, CSS, JS) con carrito, checkout y Supabase.

## Subir cambios (commit + push)

Esta carpeta **`sitio-base`** es el repositorio Git. Cada push a `main` actualiza la página online (1–2 min).

```bash
cd sitio-base
git add .
git commit -m "Describe el cambio"
git push origin main
```

Repo: https://github.com/Nahuex227/ProSport-Ober-

## Primera vez: activar GitHub Pages (solo una vez)

En GitHub, con la cuenta **Nahuex227**:

1. Repo **ProSport-Ober-** → **Settings** → **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main**, carpeta **/ (root)** → **Save**
4. Esperá 2–5 min y abrí la URL de arriba
